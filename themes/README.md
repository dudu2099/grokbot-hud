# 怎么加一个主题

一个主题就是 `themes/` 下的一个文件夹，文件夹名就是主题 id。

```
themes/<id>/
├── wallpaper.jpg     壁纸，jpg、png、webp 三选一
├── thumb.jpg         面板里的小预览图，可以没有
└── theme.json
```

`theme.json` 长这样：

```json
{
  "id": "solar-system",
  "name": "太阳系",
  "wallpaper": "wallpaper.png",
  "thumb": "thumb.jpg",
  "opacity": 0.9,
  "appearance": "dark",
  "accent": "#e89a5b",
  "credit": "作者或来源说明"
}
```

| 字段 | 规则 |
|---|---|
| `id` | 必须和文件夹名一样，只能用小写字母、数字和连字符 |
| `name` | 给人看的名字 |
| `wallpaper` | 文件夹里的图片文件名。文件要小于 4MB，长边建议不超过 2560 像素 |
| `thumb` | 可选。建议 320 像素宽，几 KB。没有的话面板里显示一块强调色 |
| `opacity` | 壁纸不透明度，0.15 到 1，不写就是 0.9 |
| `appearance` | `dark` 或 `light`。写这张图是给深色模式还是浅色模式配的 |
| `accent` | 可选。只用在悬浮面板的选中态上，不会去改 Grok Bot 自己的控件 |
| `credit` | 可选。图的来源 |

加完跑一次 `node scripts/grokbot-wallpaper.mjs list`。新主题出现在 `themes` 里就是好的，出现在 `broken` 里会写明哪条规则没过。

## 只在自己电脑上用的主题

想在面板里固定放几张自己的图，又不想动这个仓库（比如图是别人的作品，不能跟着仓库发出去），把主题文件夹放进数据目录的 `themes/` 里，格式和上面一样：

- Windows：`%APPDATA%\grokbot-wallpaper\themes\<id>\`
- Mac：`~/Library/Application Support/grokbot-wallpaper/themes/<id>/`

这里的主题排在「我的图片」后面、自带的几张前面。和自带的某一张 id 相同时，用你的这张顶替它。

只想看到自己的，在这个 `themes/` 文件夹里放一个名叫 `hide-builtin` 的空文件，自带的几张就不列了。删掉这个文件它们就回来。

## 选图的三条经验

这三条是在真窗口上试出来的。

1. **主体压到右侧或右下角，左边和中间留空。** 聊天文字落在中间那一栏，后面的画面越干净字越清楚。
2. **深浅要说实话。** `appearance` 写的是这张图配哪种模式。深色图配浅色模式的应用，字会糊，工具只能靠加厚底色来保底。
3. **图里不要有字。** 任何文字、标志、水印都会和界面上的字打架。
